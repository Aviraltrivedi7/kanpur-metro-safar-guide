# Kanpur Metro Safar Guide

A modern and aesthetic web application to guide commuters traveling on the Kanpur Metro. Features include fare calculation, route mapping, live tickers, and an eco-savings calculator.

## Technologies Used
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Getting Started

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Run the development server**
   ```bash
   npm run dev
   ```

3. **Build for production**
   ```bash
   npm run build
   ```
